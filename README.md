# OtherLanguage_Tools

这是当前的总工具库入口，用于按用途收纳不同类型的仓库内容。

## 当前结构

1. [userscript_Tools](userscript_Tools)
2. [python_Tools](python_Tools)
3. [exe_Tools](exe_Tools)
4. [archive_实验](archive_实验)

## 说明

- `userscript_Tools`：放浏览器脚本、油猴脚本等。
- `python_Tools`：放 Python 小工具。
- `exe_Tools`：放独立可执行程序、安装包、相关说明。
- `archive_实验`：放实验项目、教学项目、归档内容。

`FZ010619.github.io` 保持为单独仓库，不并入本库。
